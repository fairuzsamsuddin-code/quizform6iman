# Ujian Cubaan Semester 1 Iman Arissa

Kuiz aneka pilihan untuk STPM Penggal 1 (Ekonomi, Bahasa Melayu, Sejarah, Pengajian Am) dan MUET.

- Halaman utama: pilih subjek (`index.html`).
- Setiap sesi: 40 soalan rawak daripada bank soalan, pilihan jawapan diacak. Soalan yang belum dilihat didahulukan, jadi sesi seterusnya berbeza.
- Akhir sesi: markah (cth. 32/40), peratusan, pecahan mengikut bab dan semakan soalan yang salah.
- Bank soalan: `data/*.js`. Nota rujukan: `notes/README.md`.

Tiada pelayan diperlukan. Buka `index.html`, atau aktifkan GitHub Pages (Settings > Pages > Deploy from branch > main / root).
